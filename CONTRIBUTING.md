# Contributing Guidelines

Thank you for considering contributing to the Simple Interest Calculator project! 

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. **Report Bugs:** If you find a bug, please open an issue describing the problem, steps to reproduce it, and the expected behavior.
2. **Suggest Enhancements:** Have an idea to make this script better? Open an issue or submit a pull request with your suggestions.
3. **Submit Code Changes:**
   - Fork the repository.
   - Create a new branch for your feature or bug fix.
   - Make your changes and commit them with clear, descriptive messages.
   - Push your branch to your fork.
   - Open a Pull Request against the main repository.
4. **Improve Documentation:** Contributions to clear up instructions, fix typos, or enhance readability in `README.md` or other docs are always appreciated.
